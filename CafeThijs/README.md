# Café Thijs Website

Modern redesign of [cafethijs.nl](https://cafethijs.nl/) — De Amstelveense Bierambassade.

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- Motion (animations)
- React Router v7

## Development

```bash
npm install
npm run dev
```

## Pages

- **Home** — hero, highlights, bar section
- **Bieren** — tap, flessen, dranken
- **Over ons** — George Thijs, bierambassadeur
- **Nieuws** — updates & proeverijen
- **Contact** — borrel organiseren formulier
- **FAQ**

## Deploy

Includes `vercel.json` for SPA routing. Deploy to Vercel with default Vite settings.
